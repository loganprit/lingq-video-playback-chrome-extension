# PROTOTYPE — control placement

Three throwaway Playback Mode selector placements on LingQ's existing reader:

- `?lspc-variant=A` — footer companion
- `?lspc-variant=B` — sentence companion
- `?lspc-variant=C` — compact popover

With a LingQ lesson active in Aside Browser, run `npm run prototype:controls`, then use the purple switcher or Left/Right arrow keys.
